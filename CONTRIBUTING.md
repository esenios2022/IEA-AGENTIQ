# Guía de Contribución

¡Gracias por tu interés en contribuir a IEA-AGENTIQ!

## Cómo contribuir

1. Hacé un fork del repositorio.
2. Creá una rama para tu cambio: `git checkout -b feature/nombre-de-tu-feature`.
3. Realizá tus cambios siguiendo las convenciones del proyecto.
4. Asegurate de que las pruebas pasen: `pytest tests/`.
5. Hacé commit de tus cambios con mensajes claros y descriptivos.
6. Enviá un pull request describiendo los cambios realizados.

## Estándares de código

- Seguí las convenciones de estilo de Python (PEP 8).
- Documentá funciones y módulos cuando la lógica no sea evidente.
- Agregá pruebas para nuevas funcionalidades o correcciones de bugs.

## Reporte de issues

Si encontrás un bug o tenés una propuesta de mejora, abrí un issue describiendo:

- El comportamiento esperado y el comportamiento actual.
- Pasos para reproducir el problema (si aplica).
- Contexto adicional relevante.
